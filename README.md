# CHAOS;CHILD Winlator 启动器校验绕过补丁（修复方案）

在 **Winlator（安卓 Windows 模拟器）** 中运行《CHAOS;CHILD》PC 汉化版时，通过「启动游戏.exe」点「开始游戏」会弹出日文错误框：

> **エラー**
> **ランチャーから起動してください。**（请从启动器启动）

常规方法（改英文文件名、换回原版日文 Launcher、调整容器设置等）均无法解决。本项目提供**根因分析 + 可执行的补丁方案**，绕过启动器校验，让 `Game.exe` 直接运行即可进入游戏。

> ⚠️ 本仓库只包含修复方案与说明脚本，**不含任何游戏本体文件**（Game.exe、USRDIR 数据、说明书等均为受版权保护内容，请勿上传/分发）。

---

## 一、根因分析

`Game.exe`（2016-03-18 构建，x86 PE32）内部有一道「启动器校验」：主程序会打开一个**共享内存映射对象**，从中读取一个标记值，并与内部常量比较：

- 从「启动游戏.exe」启动时，启动器预先创建共享内存并写入正确标记 → 校验通过 → 正常进入游戏；
- 直接运行 `Game.exe`（或通过 Winlator 等环境启动）时，该共享内存握手无法建立 → 校验失败 → 弹出「ランチャーから起動してください」并退出。

关键证据（PC 实测）：
| 启动方式 | 结果 |
| --- | --- |
| 直接运行 `Game.exe`（无参数） | 弹「エラー」 |
| 直接运行 `Game.exe chaoschild`（带参数） | 仍弹「エラー」 |
| 通过「启动游戏.exe」点开始 | 正常进入游戏（窗口标题 `DIEmWin | CHAOS;CHILD`） |

结论：命令行参数不是充分条件，握手依赖**进程间共享内存**。而在 Winlator 的 Wine 环境下，该 IPC 握手未能正确传递给 `Game.exe`，因此报错。

## 二、修复原理

在 `Game.exe` 中定位到校验函数的条件跳转：

```
0046C015  test bl, bl              ; bl = 共享内存校验结果
0046C018  jne 0x46C034             ; 校验通过 -> 正常启动
0046C01A  push 0x10
0046C01C  push 0x4B96C0            ; 标题「エラー」
0046C021  push 0x4B96C8            ; 「ランチャーから起動してください。」
0046C028  call [MessageBoxA]       ; 弹错误框
0046C02E  xor al, al
0046C033  ret                      ; 返回失败
0046C034  ...                      ; 正常启动路径（含防多开检查）
```

**补丁**：把 `0046C018` 处的 `jne`（机器码 `75 1A`）改为无条件跳转 `jmp`（机器码 `EB 1A`），跳过校验错误框，直接进入正常启动路径。该修改是**机器码级**的，与运行环境（Windows / Wine / Winlator）无关，因此跨环境有效。

- 文件偏移：`0x6B418`
- 修改：`75 1A` → `EB 1A`（1 字节）

## 三、使用方法

### 方式一：使用补丁脚本（推荐）

需要本机有 Python 3：

```bash
python patch.py "D:\路径\to\Game.exe"
```

脚本会自动：
1. 校验目标偏移字节是否为预期的 `75 1A`（防止误改其他版本）；
2. 若未备份过，自动生成 `Game.exe.orig` 备份；
3. 写入补丁并提示完成。

### 方式二：手动修改（十六进制编辑器）

用任意 hex 编辑器（HxD、010 Editor 等）打开 `Game.exe`，定位到文件偏移 `0x6B418`，将 `75 1A` 改为 `EB 1A`，保存。

## 四、在 Winlator 中的操作

1. 将补丁后的 `Game.exe` 覆盖到 Winlator 容器内游戏目录；
2. **重要注意事项（实测经验）**：本模拟器环境中，首次需要先通过「启动游戏.exe」点一次「开始游戏」；之后即可**直接点击 `Game.exe` 启动**，无需每次再经启动器；
3. 直接运行 `Game.exe` 后，窗口标题出现 `CHAOS;CHILD` 即表示成功进入。

## 五、如何还原

将备份的 `Game.exe.orig` 重命名为 `Game.exe` 覆盖回去即可恢复原版行为。
